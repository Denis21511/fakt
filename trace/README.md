# TRACE — цифровые паспорта изделий

**Каждое изделие. Вся история. Один код.**

MVP для небольших производств: изделие получает цифровой паспорт и QR-код для наклейки,
покупатель сканирует код и открывает мобильную страницу с характеристиками, гарантией и документами.
Демо-данные — вымышленный производитель металлических дверей и конструкций «ФОРМАТ МЕТАЛЛ».

Это отдельное приложение внутри репозитория FAKT: свои `package.json` и `node_modules`, код FAKT не затронут.

```bash
cd trace
npm install
npm run dev      # http://localhost:5186
npm run build    # проверка типов и сборка в trace/dist
npm run preview  # собранная версия, http://localhost:5187
```

## Маршруты

| Адрес | Экран |
| --- | --- |
| `/` | Коммерческая страница продукта |
| `/app` | Панель производства |
| `/app/products` | Каталог: поиск, фильтры, таблица и карточки |
| `/app/products/new`, `/app/products/:id/edit` | Создание и редактирование в пять шагов |
| `/app/products/:id` | Карточка изделия, цифровой идентификатор, документы |
| `/app/qr` | QR-коды, три макета этикеток, PNG/SVG, печать |
| `/app/documents` | Библиотека документов |
| `/app/warranties` | Сроки гарантий на шкале времени |
| `/app/settings` | Профиль компании, фирменный цвет, публичное отображение, данные |
| `/p/:token` | Публичный паспорт — сюда ведёт QR-код |

## Хранение данных

Сервера нет. Это **демонстрационное хранилище, а не production-бэкенд**:

- изделия, документы (метаданные) и настройки — `localStorage`, ключ `trace:workspace:v1`;
- файлы (фото, PDF, логотип) — IndexedDB `trace-files`; PDF/JPG/PNG/WEBP до 10 МБ;
- данные видны только в этом браузере. Демо-набор одинаково создаётся на любом устройстве
  при первом открытии, поэтому QR-коды **демо-изделий** открываются и с телефона,
  если приложение опубликовано по доступному адресу. Изделия, созданные пользователем, — только в его браузере.
- демо-документы — настоящие PDF, которые рисуются в браузере при первом обращении
  (`src/data/demo/renderDocument.ts`) и помечены как демонстрационные.

Подключение сервера: реализовать интерфейс `TraceRepository` (`src/storage/repository.ts`)
и подменить его в `src/storage/index.ts`. Публичная страница уже работает только через
`getPassport` / `getPassportFile` / `getPublicAsset` и получает лишь разрешённые поля (`toPublicPassport`).

## Устройство

```
src/
  domain/      модели, статусы гарантии, проверка формы, сборка публичного паспорта
  storage/     контракт хранилища, localStorage + IndexedDB
  state/       Zustand: рабочее пространство и уведомления
  data/demo/   демо-компания, 12 изделий, 14 документов, генератор демо-PDF
  components/  дизайн-система, QR, этикетки и печать, паспорт, иллюстрации изделий
  pages/       экраны; editor/ — шаги мастера изделия
  styles/      токены, базовые стили, компоненты, стили экранов, печать
```

Стек: Vite, React 18, TypeScript, React Router, Zustand, Lucide, `qrcode` (кодирование QR; отрисовка — векторная),
шрифты Manrope, Inter и JetBrains Mono.
